Решения для первой итерации

Скоуп держим узким, чтобы быстро довести до рабочего состояния.

1
ДанныеЗагружаем `/api/ingredients` и `/api/prices`; на фронтенде выбираем последнюю цену по `ingredient_id`.
2
ФильтрыПоиск по названию, тип через SelectDropdown, быстрые чипы “Все / База / Специи / Соусы / Без цены”.
3
ТаблицаКолонки: название, тип, актуальная цена, количество+единица, дата обновления. Сортировка по названию, типу, цене и дате.
4
Без новых CRUD-действийРедактирование и удаление не включаем, потому что backend сейчас не имеет PUT/DELETE для ингредиентов. Добавление остается через существующую модалку.
5
СтилиИспользуем текущий Smoked Ember / BatchVault стиль, без нового визуального языка и без внешних зависимостей.
