Нет подходящего?

Создать новый ингредиент в справочнике и сразу добавить его в мой набор.

1
ID не показываемТехнический ID не помогает пользователю выбрать ингредиент. Для отладки он может быть в detail/dev view, не в списке.
2
Search-first добавлениеFlow начинается с поиска существующего справочного ингредиента, чтобы не плодить дубликаты.
3
Создание как fallbackНовый справочный ингредиент создается только если пользователь не нашел подходящий вариант.
4
После добавления нужна ценаДобавление в набор может сразу предложить добавить первую цену, но не обязано смешиваться с созданием ингредиента.
