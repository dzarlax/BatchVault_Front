Detail Cards With Packaging

The selected direction is image-free detail cards. Now choose how prominent packaging should be.

A. Package Chips Above Cards

Recommended default

Packaging is visible and fast to filter, but the screen stays simple. Add package is one small action near the package chips.

B. Package Panel

Stronger package management

Good if package count is small and package switching is the main workflow. It costs horizontal space and needs a mobile fallback.

C. Product Modal Owns Package

Minimal page, stronger modal

Packaging stays mostly inside create/edit product. This is lowest page complexity, but weaker for reviewing package coverage.
